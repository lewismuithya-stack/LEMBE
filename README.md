# Supercar Showcase 🚗💨

## Author
Lewis muithya

## Project Description
This project is a personal website themed around **supercars**, with a special highlight on the legendary **BMW M3 GTR from Need for Speed: Most Wanted (2005)**.  
It includes:
- An introductory paragraph about my passion for supercars
- A gallery of favorite cars with images and captions
- A biography section with my photo
- A contact form for visitors
- Custom CSS styling inspired by BMW M3 GTR colors (blue, red, white, black) and carbon fiber textures

## Design
The design was planned with a wireframe sketch showing the layout:
- Header at the top
- Intro section
- Gallery section
- Biography section
- Contact form
- Footer

The design file is included in this repository (`design.png`).

## Setup Instructions
1. Clone or download this repository.
2. Open `index.html` in any modern web browser.
3. Make sure `style.css` is in the same folder as `index.html`.
