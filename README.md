# Photography & Supercar Showcase 📸🚗💨

## Author
Lewis Muithya

## Project Description
This project is a personal website themed around **photography and supercars**, highlighting the artistry of capturing high-performance machines through the lens.  
It includes:
- An introductory paragraph about my passion for photography and cars
- A gallery of favorite supercar photographs with images and captions that emphasize lighting, angles, and composition
- A biography section with my photo
- A contact form for visitors
- Custom CSS styling inspired by motorsport aesthetics (bright pop colors, carbon fiber textures, performance-inspired buttons)

## Design
The design was planned with a wireframe sketch showing the layout:
- Header at the top
- Intro section
- Gallery section
- Biography section
- Contact form
- Footer

The design file is included in this repository (`design.png`).

## Setup Instructions
1. Clone or download this repository.
2. Open `index.html` in any modern web browser.
3. Make sure `style.css` is in the same folder as `index.html`.
